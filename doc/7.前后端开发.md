## 协作模式

### 并行开发流程

```
         后端                          前端
          │                              │
    ┌─────▼─────┐                  ┌─────▼─────┐
    │ 数据库设计  │                  │           │
    └─────┬─────┘                  │           │
          │                        │           │
    ┌─────▼─────┐    接口文档       │           │
    │ API 设计   │ ──────────────→  │  Mock 开发 │
    └─────┬─────┘                  │           │
          │                        │           │
    ┌─────▼─────┐                  │           │
    │ 后端实现   │ ←── 联调 ──────→ │ 页面对接   │
    └─────┬─────┘                  └─────┬─────┘
          │                              │
          └────────── 集成测试 ───────────┘
```

### 接口契约

前后端以 [5.API 接口设计.md](./5.API%20接口设计.md) 为契约：

1. 后端先定义 Swagger 注解，前端可提前查看 `http://localhost:8080/doc.html`
2. 统一响应格式 `Result<T>`，前端 `request.ts` 统一处理
3. 分页参数统一：`pageNum`、`pageSize`，返回 `PageResult<T>`
4. 权限标识统一：`{module}:{resource}:{action}`，如 `system:user:add`

## 后端开发

### 分层架构

```
Controller  →  接收请求、参数校验、权限控制、返回响应
    ↓
Service     →  业务逻辑、事务管理
    ↓
Mapper      →  数据库访问（MyBatis-Plus）
    ↓
Entity      →  数据库实体映射
```

#### Step 3：Service

```java
public interface IBizOrderService {
    PageResult<BizOrderVO> listOrders(BizOrderQueryDTO query);
    BizOrderVO getOrderById(Long id);
    void createOrder(BizOrderDTO dto);
    void updateOrder(BizOrderDTO dto);
    void deleteOrders(Long[] ids);
}

@Service
@RequiredArgsConstructor
public class BizOrderServiceImpl implements IBizOrderService {

    private final BizOrderMapper orderMapper;

    @Override
    public PageResult<BizOrderVO> listOrders(BizOrderQueryDTO query) {
        PageHelper.startPage(query.getPageNum(), query.getPageSize());
        List<BizOrder> list = orderMapper.selectOrderList(query);
        return PageResult.of(list, BizOrderVO.class);
    }

    @Override
    @Transactional
    public void createOrder(BizOrderDTO dto) {
        BizOrder order = BeanUtil.copyProperties(dto, BizOrder.class);
        order.setOrderNo(generateOrderNo());
        order.setOrderTime(LocalDateTime.now());
        orderMapper.insert(order);
    }

    private String generateOrderNo() {
        return "ORD" + DateUtil.format(new Date(), "yyyyMMddHHmmss")
            + RandomUtil.randomNumbers(4);
    }
}
```

#### Step 4：Controller

```java
@Tag(name = "订单管理")
@RestController
@RequestMapping("/business/order")
@RequiredArgsConstructor
public class BizOrderController {

    private final IBizOrderService orderService;

    @Operation(summary = "订单列表")
    @PreAuthorize("@ss.hasPermi('business:order:list')")
    @GetMapping("/list")
    public Result<PageResult<BizOrderVO>> list(BizOrderQueryDTO query) {
        return Result.success(orderService.listOrders(query));
    }

    @Operation(summary = "订单详情")
    @PreAuthorize("@ss.hasPermi('business:order:query')")
    @GetMapping("/{id}")
    public Result<BizOrderVO> getInfo(@PathVariable Long id) {
        return Result.success(orderService.getOrderById(id));
    }

    @Operation(summary = "新增订单")
    @PreAuthorize("@ss.hasPermi('business:order:add')")
    @Log(title = "订单管理", businessType = BusinessType.INSERT)
    @PostMapping
    public Result<Void> add(@Valid @RequestBody BizOrderDTO dto) {
        orderService.createOrder(dto);
        return Result.success();
    }

    @Operation(summary = "修改订单")
    @PreAuthorize("@ss.hasPermi('business:order:edit')")
    @Log(title = "订单管理", businessType = BusinessType.UPDATE)
    @PutMapping
    public Result<Void> edit(@Valid @RequestBody BizOrderDTO dto) {
        orderService.updateOrder(dto);
        return Result.success();
    }

    @Operation(summary = "删除订单")
    @PreAuthorize("@ss.hasPermi('business:order:remove')")
    @Log(title = "订单管理", businessType = BusinessType.DELETE)
    @DeleteMapping("/{ids}")
    public Result<Void> remove(@PathVariable Long[] ids) {
        orderService.deleteOrders(ids);
        return Result.success();
    }
}
```

### 全局异常处理

```java
@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: {}", e.getMessage());
        return Result.fail(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<Void> handleValidationException(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldErrors().stream()
            .map(FieldError::getDefaultMessage)
            .collect(Collectors.joining(", "));
        return Result.fail(400, msg);
    }

    @ExceptionHandler(Exception.class)
    public Result<Void> handleException(Exception e) {
        log.error("系统异常", e);
        return Result.fail(500, "系统内部错误");
    }
}
```

## 前后端联调

### 联调环境准备

```bash
# 1. 启动基础服务
docker-compose up -d mysql redis

# 2. 启动后端（端口 8080）
cd backend && mvn spring-boot:run -Dspring-boot.run.profiles=dev

# 3. 启动前端（端口 5173，代理到 8080）
cd frontend && npm run dev
```

### Vite 代理配置

```typescript
// vite.config.ts
export default defineConfig({
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true
      }
    }
  }
})
```

### 联调 Checklist

| 步骤 | 后端 | 前端 | 验证 |
|------|------|------|------|
| 1. 登录 | 返回 Token | 存储 Token，跳转首页 | 登录成功 |
| 2. 获取用户信息 | 返回 roles + permissions | 存入 Pinia | 顶部显示用户名 |
| 3. 动态路由 | 返回菜单树 | 生成路由并注册 | 侧边栏菜单正确 |
| 4. 列表查询 | 分页数据 | 表格渲染 | 数据展示正确 |
| 5. 新增 | 创建成功 | 对话框提交 | 列表刷新 |
| 6. 编辑 | 更新成功 | 回显 + 提交 | 数据更新 |
| 7. 删除 | 软删除 | 确认弹窗 | 列表移除 |
| 8. 权限按钮 | 403 拦截 | v-hasPermi 隐藏 | 无权限不可见 |

### 常见问题排查

| 现象 | 可能原因 | 排查方式 |
|------|----------|----------|
| 401 Unauthorized | Token 未携带或过期 | 检查 request 拦截器、Redis |
| 403 Forbidden | 权限标识不匹配 | 对比 `@PreAuthorize` 和 `sys_menu.perms` |
| CORS 错误 | 跨域配置缺失 | 检查后端 CorsConfig |
| 数据格式不对 | 字段名不一致 | 对比 Swagger 文档和前端 TypeScript 类型 |
| 分页 total 为 0 | PageHelper 未生效 | 检查 Service 中 `PageHelper.startPage()` |

## 代码生成

脚手架内置代码生成模块，可基于数据库表一键生成前后端 CRUD 代码。

### 使用流程

```
1. 设计并创建数据库表
       ↓
2. 代码生成 → 导入表
       ↓
3. 配置生成参数（包名、模块名、作者等）
       ↓
4. 预览代码
       ↓
5. 生成并下载 / 自定义路径生成
       ↓
6. 将代码放入项目对应目录
       ↓
7. 配置菜单和权限
       ↓
8. 按需调整业务逻辑
```

### 生成配置说明

| 配置项 | 示例 | 说明 |
|--------|------|------|
| 表名 | `biz_order` | 数据库表名 |
| 实体类名 | `BizOrder` | Java 实体类 |
| 包路径 | `com.company.rbac` | Java 包名 |
| 模块名 | `business` | 模块目录 |
| 业务名 | `order` | URL 路径片段 |
| 功能名 | `订单` | 页面标题 |
| 模板类型 | `crud` / `tree` | CRUD 或树形 |
| 作者 | `developer` | 代码注释作者 |

### 生成产物


## 文件上传

### 后端实现

```java
@PostMapping("/upload")
public Result<FileVO> upload(@RequestParam("file") MultipartFile file) {
    // 校验文件类型和大小
    String originalName = file.getOriginalFilename();
    String extension = FileUtil.getExtension(originalName);
    if (!ALLOWED_EXTENSIONS.contains(extension)) {
        throw new BusinessException("不支持的文件类型");
    }
    if (file.getSize() > MAX_FILE_SIZE) {
        throw new BusinessException("文件大小超过限制");
    }

    // 生成存储路径
    String fileName = IdUtil.fastUUID() + "." + extension;
    String filePath = uploadPath + "/" + DateUtil.today() + "/" + fileName;
    FileUtil.writeBytes(file.getBytes(), filePath);

    // 记录文件信息
    SysFile sysFile = new SysFile();
    sysFile.setFileName(originalName);
    sysFile.setFilePath(filePath);
    sysFile.setFileSize(file.getSize());
    fileMapper.insert(sysFile);

    return Result.success(FileVO.of(sysFile));
}
```

### 日志切面自动记录

```java
@Aspect
@Component
public class LogAspect {

    @Around("@annotation(controllerLog)")
    public Object around(ProceedingJoinPoint point, Log controllerLog) throws Throwable {
        long startTime = System.currentTimeMillis();
        SysOperLog operLog = new SysOperLog();
        operLog.setTitle(controllerLog.title());
        operLog.setBusinessType(controllerLog.businessType().ordinal());
        operLog.setOperName(SecurityUtils.getUsername());
        operLog.setOperIp(ServletUtils.getClientIP());
        operLog.setOperUrl(ServletUtils.getRequestURI());
        operLog.setOperParam(JSON.toJSONString(point.getArgs()));

        try {
            Object result = point.proceed();
            operLog.setStatus(0);
            operLog.setJsonResult(JSON.toJSONString(result));
            return result;
        } catch (Exception e) {
            operLog.setStatus(1);
            operLog.setErrorMsg(e.getMessage());
            throw e;
        } finally {
            operLog.setCostTime(System.currentTimeMillis() - startTime);
            operLog.setOperTime(LocalDateTime.now());
            operLogService.save(operLog);
        }
    }
}
```
