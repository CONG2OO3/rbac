## Git 配置

### 安装 Git

```bash
# Windows
choco install git -y

# macOS
brew install git

# Linux
sudo apt install -y git
```

### 全局配置

```bash
# 设置用户名和邮箱（提交记录中使用）
git config --global user.name "你的姓名"
git config --global user.email "your.email@example.com"

# 设置默认分支名
git config --global init.defaultBranch main

# 设置换行符处理（Windows 推荐）
git config --global core.autocrlf true

# macOS / Linux
git config --global core.autocrlf input
```

### SSH 密钥（连接 GitHub / GitLab）

```bash
# 生成 SSH 密钥
ssh-keygen -t ed25519 -C "your.email@example.com"

# 查看公钥，复制到 Git 平台
cat ~/.ssh/id_ed25519.pub
```

### 克隆项目

```bash
git clone <仓库地址> rbac
cd rbac
```

## Node.js / Java / Python

本项目采用前后端分离架构：

- **前端**：Node.js + Vue 3
- **后端**：Java 17 + Spring Boot 3
- **脚本/工具**：Python 3（可选，用于数据迁移、自动化脚本）

**版本要求：Node.js 18 LTS 或 20 LTS**

# Windows: 安装 nvm-windows

npm config set registry https://registry.npmmirror.com

```bash
cd frontend
npm install
# 或使用 pnpm
pnpm install
```

**版本要求：JDK 17+**

## 数据库

本项目使用 **MySQL 8.0** 作为主数据库。

### 安装 MySQL

**方式一：Docker（推荐）**

```bash
docker run -d \
  --name rbac-mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=root123456 \
  -e MYSQL_DATABASE=rbac \
  -e MYSQL_USER=rbac \
  -e MYSQL_PASSWORD=rbac123456 \
  -v rbac-mysql-data:/var/lib/mysql \
  mysql:8.0 \
  --character-set-server=utf8mb4 \
  --collation-server=utf8mb4_unicode_ci
```

**方式二：本地安装**

```bash
# Windows
choco install mysql -y

# macOS
brew install mysql
brew services start mysql

# Ubuntu
sudo apt install -y mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql
```

### 创建数据库与用户

```sql
-- 登录 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE IF NOT EXISTS rbac
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;

-- 创建专用用户
CREATE USER 'rbac'@'%' IDENTIFIED BY 'rbac123456';
GRANT ALL PRIVILEGES ON rbac.* TO 'rbac'@'%';
FLUSH PRIVILEGES;
```

### 初始化表结构

```bash
# 执行 SQL 初始化脚本（路径以实际项目为准）
mysql -u rbac -p rbac < backend/src/main/resources/db/schema.sql
mysql -u rbac -p rbac < backend/src/main/resources/db/data.sql
```

### 连接信息

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 主机 | `localhost` | 本地开发 |
| 端口 | `3306` | MySQL 默认端口 |
| 数据库名 | `rbac` | 项目数据库 |
| 用户名 | `rbac` | 应用专用账号 |
| 密码 | `rbac123456` | 开发环境密码，生产环境请修改 |

## Redis

本项目使用 **Redis** 存储登录 Token、权限缓存及会话信息。

### 安装 Redis

**方式一：Docker（推荐）**

```bash
docker run -d \
  --name rbac-redis \
  -p 6379:6379 \
  -v rbac-redis-data:/data \
  redis:7-alpine \
  redis-server --appendonly yes
```

**方式二：本地安装**

```bash
# Windows（推荐使用 WSL2 或 Memurai）
# macOS
brew install redis
brew services start redis

# Ubuntu
sudo apt install -y redis-server
sudo systemctl start redis
sudo systemctl enable redis
```

### 验证连接

```bash
redis-cli ping
# 应返回 PONG
```

### 连接信息

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 主机 | `localhost` | 本地开发 |
| 端口 | `6379` | Redis 默认端口 |
| 密码 | 无 | 开发环境不设密码 |
| 数据库 | `0` | 默认 DB |

## 环境变量

### 后端环境变量

在后端项目根目录创建 `.env` 或在 `application-dev.yml` 中配置：

```yaml
# application-dev.yml 示例
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/rbac?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: rbac
    password: rbac123456
    driver-class-name: com.mysql.cj.jdbc.Driver

  redis:
    host: localhost
    port: 6379
    password:
    database: 0

  # JWT 配置
jwt:
  secret: your-jwt-secret-key-change-in-production
  expiration: 86400000  # 24 小时，单位毫秒

server:
  port: 8080
```

或使用环境变量（`.env` 文件）：

```env
# 数据库
DB_HOST=localhost
DB_PORT=3306
DB_NAME=rbac
DB_USER=rbac
DB_PASSWORD=rbac123456

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=

# JWT
JWT_SECRET=your-jwt-secret-key-change-in-production
JWT_EXPIRATION=86400000

# 服务端口
SERVER_PORT=8080
```

> **注意**：`.env` 文件包含敏感信息，请勿提交到 Git 仓库。项目根目录的 `.gitignore` 中应包含 `.env`。

### 前端环境变量

在前端项目根目录创建 `.env.development`：

```env
# API 基础地址
VITE_API_BASE_URL=http://localhost:8080/api

# 应用标题
VITE_APP_TITLE=RBAC 权限管理系统
```

## 项目启动

### 启动顺序

```
MySQL → Redis → 后端服务 → 前端服务
```

### 1. 启动基础服务

```bash
# 使用 Docker Compose 一键启动（推荐）
docker-compose up -d mysql redis

# 或分别启动
docker start rbac-mysql
docker start rbac-redis
```

### 2. 启动后端

```bash
cd backend

# 开发模式（Spring Boot DevTools 热重载）
mvn spring-boot:run -Dspring-boot.run.profiles=dev

# 或使用 IDE 直接运行主类
# com.example.rbac.RbacApplication
```

后端启动成功后访问：

- 接口文档：http://localhost:8080/doc.html （Swagger / Knife4j）
- 健康检查：http://localhost:8080/actuator/health

### 3. 启动前端

```bash
cd frontend

# 开发模式
npm run dev

# 或使用 pnpm
pnpm dev
```

前端启动成功后访问：

- 开发地址：http://localhost:5173

### 4. 默认账号

| 角色 | 用户名 | 密码 | 说明 |
|------|--------|------|------|
| 超级管理员 | `admin` | `admin123` | 拥有全部权限 |
| 普通用户 | `user` | `user123` | 仅基础权限 |

> 首次启动请通过初始化 SQL 脚本导入默认账号，或通过注册接口创建。

### 5. 一键启动脚本（可选）

**Windows（`start-dev.bat`）：**

```bat
@echo off
echo Starting RBAC Development Environment...
docker start rbac-mysql rbac-redis
start cmd /k "cd backend && mvn spring-boot:run -Dspring-boot.run.profiles=dev"
timeout /t 15
start cmd /k "cd frontend && npm run dev"
echo All services started!
```

**macOS / Linux（`start-dev.sh`）：**

```bash
#!/bin/bash
echo "Starting RBAC Development Environment..."
docker start rbac-mysql rbac-redis
cd backend && mvn spring-boot:run -Dspring-boot.run.profiles=dev &
sleep 15
cd ../frontend && npm run dev &
echo "All services started!"
```

## 常见问题

### Q1：MySQL 连接失败 `Communications link failure`

**原因**：MySQL 服务未启动，或端口被占用。

**解决**：

```bash
# 检查 MySQL 是否运行
docker ps | grep rbac-mysql
# 或
sudo systemctl status mysql

# 检查端口占用
netstat -ano | findstr 3306   # Windows
lsof -i :3306                 # macOS / Linux

# 重启 MySQL
docker restart rbac-mysql
```

---

### Q2：Redis 连接超时

**原因**：Redis 未启动，或配置了错误的 host/port。

**解决**：

```bash
# 验证 Redis 是否运行
redis-cli ping

# 检查配置文件中 host 是否为 localhost
grep -r "redis" backend/src/main/resources/
```

---

### Q3：`npm install` 报错或速度极慢

**原因**：网络问题或 Node.js 版本不兼容。

**解决**：

```bash
# 切换国内镜像
npm config set registry https://registry.npmmirror.com

# 清除缓存重试
npm cache clean --force
rm -rf node_modules package-lock.json
npm install

# 确认 Node.js 版本
node -v  # 需要 18+ 或 20+
```

---

### Q4：Java 编译报错 `Unsupported class file major version`

**原因**：JDK 版本不匹配，项目需要 JDK 17。

**解决**：

```bash
# 查看当前 Java 版本
java -version

# 切换 JDK 版本（macOS）
export JAVA_HOME=$(/usr/libexec/java_home -v 17)

# Windows：在系统环境变量中设置 JAVA_HOME 指向 JDK 17 目录
```

---

### Q5：前端请求后端接口 CORS 跨域错误

**原因**：后端未配置跨域，或前端 API 地址配置错误。

**解决**：

1. 确认 `.env.development` 中 `VITE_API_BASE_URL` 指向正确的后端地址
2. 检查后端 `CorsConfig` 是否允许前端域名（开发环境通常为 `http://localhost:5173`）

---

### Q6：端口被占用 `Address already in use`

**原因**：8080 或 5173 端口已被其他进程占用。

**解决**：

```bash
# Windows：查找并结束占用进程
netstat -ano | findstr 8080
taskkill /PID <进程ID> /F

# macOS / Linux
lsof -i :8080
kill -9 <进程ID>

# 或修改配置文件中的端口号
```

---

### Q7：数据库表不存在 `Table 'rbac.xxx' doesn't exist`

**原因**：未执行数据库初始化脚本。

**解决**：

```bash
# 重新执行初始化 SQL
mysql -u rbac -p rbac < backend/src/main/resources/db/schema.sql
mysql -u rbac -p rbac < backend/src/main/resources/db/data.sql
```

---

### Q8：登录后 Token 立即失效

**原因**：Redis 未正常运行，或 JWT 密钥配置不一致。

**解决**：

1. 确认 Redis 服务正常：`redis-cli ping`
2. 检查 `JWT_SECRET` 环境变量是否在重启后保持一致
3. 清除浏览器 LocalStorage 后重新登录

---

### Q9：Docker 容器启动失败

**原因**：端口冲突或 Docker 未运行。

**解决**：

```bash
# 查看容器日志
docker logs rbac-mysql
docker logs rbac-redis

# 删除旧容器重新创建
docker rm -f rbac-mysql rbac-redis
# 重新执行 docker run 命令

# 确认 Docker Desktop 已启动（Windows / macOS）
```

---

### Q10：Maven 依赖下载失败

**原因**：网络问题或 Maven 仓库配置错误。

**解决**：

在 `~/.m2/settings.xml` 中配置阿里云镜像：

```xml
<mirrors>
  <mirror>
    <id>aliyun</id>
    <mirrorOf>central</mirrorOf>
    <name>Aliyun Maven Mirror</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

## 附录：推荐 Docker Compose 配置

在项目根目录创建 `docker-compose.yml`，一键启动所有基础服务：

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: rbac-mysql
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: root123456
      MYSQL_DATABASE: rbac
      MYSQL_USER: rbac
      MYSQL_PASSWORD: rbac123456
    volumes:
      - rbac-mysql-data:/var/lib/mysql
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci

  redis:
    image: redis:7-alpine
    container_name: rbac-redis
    ports:
      - "6379:6379"
    volumes:
      - rbac-redis-data:/data
    command: redis-server --appendonly yes

volumes:
  rbac-mysql-data:
  rbac-redis-data:
```

启动命令：

```bash
docker-compose up -d
```
