## 部署架构

### 生产环境架构

```
                    ┌─────────────┐
                    │   用户浏览器  │
                    └──────┬──────┘
                           │ HTTPS (443)
                    ┌──────▼──────┐
                    │    Nginx     │  反向代理 + 静态资源 + SSL
                    │  (80/443)    │
                    └──┬───────┬──┘
                       │       │
              ┌────────▼──┐ ┌──▼──────────┐
              │  前端静态   │ │  后端 API    │
              │  (dist/)   │ │  (8080)     │
              └────────────┘ └──────┬──────┘
                                    │
                    ┌───────────────┼───────────────┐
                    │               │               │
             ┌──────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
             │  MySQL 8.0  │ │  Redis 7.x  │ │  文件存储    │
             │  (3306)     │ │  (6379)     │ │  (/data)    │
             └─────────────┘ └─────────────┘ └─────────────┘
```

### 服务器配置建议

| 环境 | CPU | 内存 | 磁盘 | 说明 |
|------|-----|------|------|------|
| 开发 | 2 核 | 4 GB | 50 GB | 本地或单机 |
| 测试 | 2 核 | 4 GB | 50 GB | 单机部署 |
| 生产（小型） | 4 核 | 8 GB | 100 GB | 单机 Docker Compose |
| 生产（中型） | 8 核 | 16 GB | 200 GB | 前后端分离 + 数据库独立 |

## 环境准备

### 服务器基础环境

```bash
# Ubuntu 22.04 示例

# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 安装 Docker Compose
sudo apt install -y docker-compose-plugin

# 安装 Nginx（非 Docker 部署时使用）
sudo apt install -y nginx

# 创建项目目录
sudo mkdir -p /opt/rbac/{app,logs,upload,backup}
sudo chown -R $USER:$USER /opt/rbac
```

### 防火墙配置

```bash
# 开放必要端口
sudo ufw allow 22      # SSH
sudo ufw allow 80      # HTTP
sudo ufw allow 443     # HTTPS
sudo ufw enable

# 数据库和 Redis 不对外开放，仅内网访问
```

### 域名与 SSL

```bash
# 使用 Certbot 申请免费 SSL 证书
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

## 构建打包

### 后端打包

```bash
cd backend

# 生产环境打包（跳过测试，生产建议先跑完测试）
mvn clean package -DskipTests -Pprod

# 产物路径
ls -la target/rbac-1.0.0.jar
```

**生产配置 `application-prod.yml`：**

```yaml
spring:
  datasource:
    url: jdbc:mysql://${DB_HOST:mysql}:${DB_PORT:3306}/rbac?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: ${DB_USER:rbac}
    password: ${DB_PASSWORD}
  redis:
    host: ${REDIS_HOST:redis}
    port: ${REDIS_PORT:6379}
    password: ${REDIS_PASSWORD:}

server:
  port: 8080

jwt:
  secret: ${JWT_SECRET}
  expiration: 86400000

logging:
  file:
    path: /opt/rbac/logs
  level:
    root: INFO
    com.company.rbac: INFO

file:
  upload-path: /opt/rbac/upload
```

### 前端打包

```bash
cd frontend

# 安装依赖
npm ci

# 生产构建
npm run build

# 产物路径
ls -la dist/
```

**生产环境变量 `.env.production`：**

```env
VITE_API_BASE_URL=/api
VITE_APP_TITLE=企业开发脚手架
```

## Docker 部署

### 项目 Dockerfile

**后端 Dockerfile：**

```dockerfile
# backend/Dockerfile
FROM eclipse-temurin:17-jre-alpine

WORKDIR /app

COPY target/rbac-*.jar app.jar

ENV JAVA_OPTS="-Xms512m -Xmx1024m -XX:+UseG1GC"

EXPOSE 8080

ENTRYPOINT ["sh", "-c", "java $JAVA_OPTS -jar app.jar --spring.profiles.active=prod"]
```

**前端 Dockerfile：**

```dockerfile
# frontend/Dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

### Docker Compose 生产配置

```yaml
# docker-compose.prod.yml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: rbac-mysql
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: rbac
      MYSQL_USER: rbac
      MYSQL_PASSWORD: ${DB_PASSWORD}
    volumes:
      - mysql-data:/var/lib/mysql
      - ./backend/src/main/resources/db/schema.sql:/docker-entrypoint-initdb.d/01-schema.sql
      - ./backend/src/main/resources/db/data.sql:/docker-entrypoint-initdb.d/02-data.sql
    ports:
      - "127.0.0.1:3306:3306"
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    container_name: rbac-redis
    restart: always
    command: redis-server --requirepass ${REDIS_PASSWORD} --appendonly yes
    volumes:
      - redis-data:/data
    ports:
      - "127.0.0.1:6379:6379"
    healthcheck:
      test: ["CMD", "redis-cli", "-a", "${REDIS_PASSWORD}", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: rbac-backend
    restart: always
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_healthy
    environment:
      DB_HOST: mysql
      DB_PORT: 3306
      DB_USER: rbac
      DB_PASSWORD: ${DB_PASSWORD}
      REDIS_HOST: redis
      REDIS_PORT: 6379
      REDIS_PASSWORD: ${REDIS_PASSWORD}
      JWT_SECRET: ${JWT_SECRET}
    volumes:
      - ./logs:/opt/rbac/logs
      - ./upload:/opt/rbac/upload
    ports:
      - "127.0.0.1:8080:8080"

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: rbac-frontend
    restart: always
    ports:
      - "127.0.0.1:80:80"

volumes:
  mysql-data:
  redis-data:
```

### 环境变量文件

```env
# .env.prod（不要提交到 Git）
MYSQL_ROOT_PASSWORD=your-strong-root-password
DB_PASSWORD=your-strong-db-password
REDIS_PASSWORD=your-strong-redis-password
JWT_SECRET=your-256-bit-jwt-secret-key-change-me
```

### 部署命令

```bash
# 1. 构建前后端
cd backend && mvn clean package -DskipTests -Pprod
cd ../frontend && npm ci && npm run build

# 2. 上传到服务器
scp -r . user@server:/opt/rbac/app/

# 3. 在服务器上启动
cd /opt/rbac/app
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d

# 4. 查看状态
docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs -f backend
```

## Nginx 配置

### 反向代理配置

```nginx
# /etc/nginx/sites-available/rbac
upstream backend {
    server 127.0.0.1:8080;
    keepalive 32;
}

server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    ssl_certificate     /etc/letsencrypt/live/your-domain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.com/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;

    # 前端静态资源
    location / {
        root /opt/rbac/app/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;

        # 静态资源缓存
        location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2)$ {
            expires 30d;
            add_header Cache-Control "public, immutable";
        }
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_connect_timeout 30s;
        proxy_read_timeout 60s;
        proxy_send_timeout 60s;
    }

    # 文件上传大小限制
    client_max_body_size 50m;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    # 访问日志
    access_log /opt/rbac/logs/nginx-access.log;
    error_log  /opt/rbac/logs/nginx-error.log;
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/rbac /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 数据库部署

### 生产数据库初始化

```bash
# 首次部署
docker exec -i rbac-mysql mysql -u root -p${MYSQL_ROOT_PASSWORD} rbac < schema.sql
docker exec -i rbac-mysql mysql -u root -p${MYSQL_ROOT_PASSWORD} rbac < data.sql
```

### 增量升级

```bash
# 按版本顺序执行 migration 脚本
for script in migration/V*.sql; do
  echo "Executing $script..."
  docker exec -i rbac-mysql mysql -u rbac -p${DB_PASSWORD} rbac < "$script"
done
```

### 数据备份

```bash
#!/bin/bash
# /opt/rbac/scripts/backup-db.sh

BACKUP_DIR=/opt/rbac/backup
DATE=$(date +%Y%m%d_%H%M%S)
FILENAME="rbac_${DATE}.sql.gz"

docker exec rbac-mysql mysqldump -u root -p${MYSQL_ROOT_PASSWORD} rbac | gzip > "${BACKUP_DIR}/${FILENAME}"

# 保留最近 30 天备份
find ${BACKUP_DIR} -name "rbac_*.sql.gz" -mtime +30 -delete

echo "Backup completed: ${FILENAME}"
```

```bash
# 添加定时任务（每天凌晨 2 点备份）
crontab -e
0 2 * * * /opt/rbac/scripts/backup-db.sh >> /opt/rbac/logs/backup.log 2>&1
```

## CI/CD 流水线

### GitHub Actions 完整流水线

```yaml
# .github/workflows/deploy.yml
name: Build and Deploy

on:
  push:
    branches: [main]
    tags: ['v*']

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with:
          java-version: '17'
          distribution: 'temurin'
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Backend Test
        run: cd backend && mvn test
      - name: Frontend Test
        run: cd frontend && npm ci && npm run lint && npm run test

  build:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-java@v4
        with:
          java-version: '17'
          distribution: 'temurin'
      - name: Build Backend
        run: cd backend && mvn clean package -DskipTests -Pprod

      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Build Frontend
        run: cd frontend && npm ci && npm run build

      - name: Upload Artifacts
        uses: actions/upload-artifact@v4
        with:
          name: build-artifacts
          path: |
            backend/target/rbac-*.jar
            frontend/dist/

  deploy:
    needs: build
    runs-on: ubuntu-latest
    if: startsWith(github.ref, 'refs/tags/v')
    steps:
      - name: Download Artifacts
        uses: actions/download-artifact@v4
        with:
          name: build-artifacts

      - name: Deploy to Server
        uses: appleboy/ssh-action@v1
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SERVER_SSH_KEY }}
          script: |
            cd /opt/rbac/app
            docker compose -f docker-compose.prod.yml down
            # 更新产物后重新启动
            docker compose -f docker-compose.prod.yml --env-file .env.prod up -d
            docker compose -f docker-compose.prod.yml logs --tail=50 backend
```

### 手动部署脚本

```bash
#!/bin/bash
# deploy.sh
set -e

SERVER="user@your-server.com"
APP_DIR="/opt/rbac/app"

echo "=== 1. 构建后端 ==="
cd backend && mvn clean package -DskipTests -Pprod && cd ..

echo "=== 2. 构建前端 ==="
cd frontend && npm ci && npm run build && cd ..

echo "=== 3. 上传到服务器 ==="
rsync -avz --delete \
  backend/target/rbac-*.jar \
  frontend/dist/ \
  docker-compose.prod.yml \
  ${SERVER}:${APP_DIR}/

echo "=== 4. 重启服务 ==="
ssh ${SERVER} "cd ${APP_DIR} && docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build"

echo "=== 部署完成 ==="
```

- [ ] 服务全部启动正常（`docker compose ps`）

### 安全加固

- [ ] 修改默认管理员密码
- [ ] 关闭不必要的端口（3306、6379、8080 仅内网）

## 回滚方案

### 应用回滚

```bash
# 方式 1：回滚到上一个 Docker 镜像
docker compose -f docker-compose.prod.yml down
docker tag rbac-backend:previous rbac-backend:latest
docker compose -f docker-compose.prod.yml up -d

# 方式 2：使用 Git Tag 重新部署
git checkout v1.0.0
./deploy.sh
```

### 数据库回滚

```bash
# 1. 停止应用（避免写入）
docker stop rbac-backend

# 2. 执行回滚 SQL
docker exec -i rbac-mysql mysql -u rbac -p rbac < rollback/V1.1.0__rollback.sql

# 3. 或从备份恢复
gunzip < /opt/rbac/backup/rbac_20260915_020000.sql.gz | \
  docker exec -i rbac-mysql mysql -u root -p rbac

# 4. 重启应用
docker start rbac-backend
```

### 回滚决策

| 问题级别 | 现象 | 处理方式 |
|----------|------|----------|
| P0 紧急 | 服务不可用、数据丢失 | 立即回滚应用 + 数据库 |
| P1 严重 | 核心功能不可用 | 回滚应用 |
| P2 一般 | 非核心功能异常 | 热修复或下次发版 |
| P3 轻微 | UI 问题、文案错误 | 记录 Issue，下次发版 |

## 常见问题

### Q1：容器启动后后端连接数据库失败

```bash
# 检查 MySQL 是否就绪
docker compose logs mysql

# 确认网络连通
docker exec rbac-backend ping mysql

# 检查环境变量
docker exec rbac-backend env | grep DB_
```

### Q2：前端页面刷新 404

Nginx 未配置 `try_files`，确保：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

### Q3：文件上传失败

```bash
# 检查上传目录权限
ls -la /opt/rbac/upload
sudo chown -R 1000:1000 /opt/rbac/upload

# 检查 Nginx 上传大小限制
# client_max_body_size 50m;
```

### Q4：内存溢出 OOM

```bash
# 调整 JVM 参数
ENV JAVA_OPTS="-Xms512m -Xmx1024m -XX:+UseG1GC -XX:+HeapDumpOnOutOfMemoryError"

# 查看堆转储
ls /opt/rbac/logs/*.hprof
```

### Q5：SSL 证书过期

```bash
# 续期
sudo certbot renew

# 自动续期（Certbot 默认配置 cron）
sudo certbot renew --dry-run
```
